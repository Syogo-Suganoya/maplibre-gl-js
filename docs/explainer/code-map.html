01

システム構成

MapLibre GL JS は、ブラウザの中の3か所で動きます。画面と操作を受け持つメインスレッド、タイルの解析を受け持つ Web Worker、描画を受け持つ GPU です。サーバーは持たず、スタイル・タイル・フォント・スプライトを HTTP（または addProtocol で登録した関数）で取ってきます。

メインスレッドWeb WorkerGPU外部・共通

ワーカーはページ全体で1つのプールを共有し、地図ごとに Dispatcher がプールの各ワーカーと話す Actor を持ちます。ワーカーの数は Safari 以外で1、Safari では論理コア数の半分（1〜3）です（src/util/worker_pool.ts）。ローカルでは npm run start で http://localhost:9966 に開発用のサーバーが立ち、/test/examples/3d-terrain.html のようなサンプルで、手元のビルド（dist/）の動きを確かめられます。

レイヤー構成

3つの場所それぞれで、上から下へ呼び出します。下の段は上の段を知りません。たとえば Bucket は自分がどのタイルの中にあるかを知らず、draw_*.ts は style.json を読みません。

↓

↓

↓

↓

WebGL2 の状態を覚えておき、変わったときだけ設定する

守られている決まり

ワーカーは DOM にさわらない

ワーカーで動くコード（source/*worker*.ts・data/・symbol/ の多く）は window や document を使えません。画像やフォントが要るときは、メインスレッドに GG・GI のメッセージで頼みます。

送るクラスは登録する

ワーカーとやりとりするクラスは、ファイルの最後で register('FillBucket', FillBucket) のように登録します。登録しないと、送った先でただのオブジェクトになります。

型は style-spec から生成

レイヤーのプロパティの型（*_properties.g.ts）は style-spec から生成します。プロパティを足すときは、先に style-spec 側を直します。

テストは公開 API から

リポジトリの AGENTS.md は、_ で始まるメソッドを使わずに公開 API で確かめること、通信は fakeServer で偽物にすることを求めています。

06

データモデル

MapLibre にデータベースはありません。その代わり、メモリの中のオブジェクトが「1対多」でつながっています。Map 1つに Style 1つ、Style にソースの数だけ TileManager、その中にタイル、タイルの中にレイヤーの family の数だけ Bucket がぶら下がります。

レイヤーと Bucket は1対1ではない

横断的な仕組みの場所

特定の機能に属さず、どこからでも使われる仕組みの置き場所です。

ワーカーと通信

ワーカーとのメッセージ
Actor が postMessage に id を付け、返事を Promise で受け取る。メッセージの種類は actor_messages.ts に23個
ワーカーの数と共有
ページに1つのプール。setWorkerCount・prewarm で調整できる
ワーカーへのデータの受け渡し
クラスを register しておくと、postMessage を通っても同じクラスに戻る。ArrayBuffer はコピーせず移す
ネットワーク
fetch と XHR、画像の同時取得数の制限、取り消し

時間とイベント

イベント
on・once・off と、ソース → Style → Map へのイベントの伝わり方
フレームと時刻
requestAnimationFrame・止められる時計・次のフレームの待ち行列
設定値
画像の同時取得数、キャッシュするズームの段数

GPU

シェーダー
GLSL 本体と、ビルドで生成される .g.ts。#pragma maplibre の展開
WebGL の状態
ブレンド・深度・ステンシルの設定を覚えて、無駄な切りかえを省く

生成コードと仕様

生成コード（*.g.ts）
直接書きかえない。npm run codegen で作り直す
スタイル仕様
書ける項目・式・検証・diff は別パッケージ
公開するもの
maplibregl.* として外に出すものの一覧と、見た目の CSS

ユニットテスト
ソースの隣の *.test.ts。通信は nise の fakeServer で偽物にする
描画・検索のテスト
style.json と期待する画像・JSON の組
ビルドとベンチマーク
配布ファイルの大きさ、速さの計測

プルリクエストごとの自動チェック
