01

何をするライブラリ？

スマホの地図のように、指で動かせる地図を Web ページに出すライブラリ（便利な関数の集まり）です。

✍️ 使う人が書くこと

  • 地図を出す場所
  • どんな色で描くか（スタイル）
  • 最初に見せる場所

🤖 MapLibre がやること

  • 地図のデータを集める
  • 読み解いて形にする
  • 1秒に最大60回描き直す
  • 文字が重ならないように選ぶ

同じデータでも、スタイルを変えると別の地図になる

02

全体の地図

仕事をするのは、ブラウザの中の3人の係です。

🧑‍💼表の係（メインスレッド）
画面と操作の担当。ここが重い計算で止まると、地図がカクカクする
👷裏方（Web Worker）
画面にはさわれないが、表の係と同時に計算できる
🎨GPU
三角形を何万個も同時に塗れる。WebGL2 で使う
💬 係どうしはメッセージで話す

{type: 'LT', data: …} のような手紙を送り合います（LT = loadTile）。手紙の種類は23個です。
